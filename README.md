搜"三网直连 VPS"的人，多半就是在找这个问题的解法。这篇文章把线路名词、验证方法、套餐档位和选择逻辑按顺序讲清楚。

## 三网直连，直连的到底是什么

先拆概念。"三网"指的是中国大陆的三家基础运营商：电信、联通、移动。这三家各自拥有独立的国际出口和跨境海缆资源，互不共用。所以同一台海外服务器，电信用户访问是 150ms，移动用户访问可能是 400ms 还带丢包——不是服务器的问题，是路径的问题。

"直连"在行业里的意思，是数据包出了国境之后走运营商自己的精品网络回国，不绕第三国、不挤公共骨干网。

要理解它的价值，得先认识三条"普通路"和三条"高速路"：

- **163 骨干网（电信 AS4134）**、**169 网络（联通 AS4837）**、**CMI（移动 AS58453）**：用户量最大、带宽最充裕，也最便宜。晚高峰拥堵严重，延迟翻倍、丢包飙升是常态。
- **CN2 GIA（电信 AS4809）**：电信下一代承载网的高端部分，去程回程都走 CN2，路由里能看到 59.43 开头的节点。容量比 163 小，但用户少，晚高峰表现稳定。
- **AS9929（联通 CU VIP）**：联通精品网，负载率低，链路上跑的流量少，对丢包敏感的业务很适合。
- **CMIN2（移动 AS58807）**：移动对标 CN2 GIA 的高端产品，有独立的出海通道和更高的 QoS 优先级。过去移动用户访问海外服务器经常绕路欧洲，CMIN2 就是为解决这个建的。

还有一个经常被忽略的点：**去程和回程通常不是同一条路**。去程指你到服务器，回程指服务器回到你。对国内用户来说，真正影响日常体感的是回程——因为下载、看网页、拉流媒体，数据都是从服务器往你这边跑。所以判断一条线路好不好，不能只看商家写的"去程优化"。

## 哪些"三网直连"其实是文字游戏

这个词现在被用得很松，几乎每家都能写。看的时候重点核对三件事。

**第一，是不是只有回程优化。** 有的商家标"三网 CN2 GIA"，实际只有电信回程走 CN2，联通和移动回程照样绕。这种写法不算骗人，但它不是完整的三网直连。

**第二，是不是把国际线路包装成优化线路。** 有些套餐标着"三网 BGP"，实际是中国方向完全没优化，只对海外用户友好。名字里有"三网"不代表中国方向有好线路。

**第三，是不是只有去程。** 去程走 CN2，回程绕美国回中国，这种机器白天测试好看，晚上体感崩。

验证方式其实不复杂。拿到测试 IP 后，用 `traceroute` 或 `mtr` 从国内分别跑电信、联通、移动三个方向的回程。看到 59.43 开头的节点，说明走了 CN2 GIA；看到 202.97，说明在 163 骨干网上；看到 9929 或 58807 段，分别对应联通精品网和移动 CMIN2。很多商家会公开自己的 Looking Glass 测试页面，也可以直接在上面出路由。

> 一个实用判断：如果商家只给了国内 ping 值，不给回程路由截图，也不提供测试 IP，那么它写的线路描述基本没法验证。

## Pro、EB、T1：三个档位分别对应什么人

聊三网直连绕不开 DMIT，它在这条赛道里被反复提起的原因比较具体：洛杉矶、香港、东京三个机房，每个机房按网络质量切成三条产品线，而不是把所有套餐混在一起卖。

- **Premium（Pro）**：三网回程走电信 CN2 GIA（AS4809）。以洛杉矶为例，电信去程走 GIA，联通去程直连 AS4837，移动去程经香港移动 AS58453，三网回程统一回到 AS4809。这是中国方向最好的一档。
- **Eyeball（EB）**：回程走联通 9929 + 移动 CMIN2 组合，电信方向在 AS9929 与 AS58807 之间做负载分配。同等配置下流量给的比 Pro 多，价格低一些。
- **Tier 1（T1）**：国际 BGP 线路，**没有**中国方向优化。它便宜、带宽大、流量多，但如果你在国内，选它就是在给自己找麻烦。

拿洛杉矶 AN5 系列的 Pro 档举例：电信去程 GIA（AS4809），联通去程直连 AS4837，移动去程经香港移动（AS58453），三网回程全部落在 GIA（AS4809）上。这个结构就是"三网直连"在实践里的标准答案。

## 几个常见问题

**CN2 GIA、9929、CMIN2 哪个最好？** 没有统一答案。CN2 GIA 的优势是跨运营商调度能力强，电信用户体验好；9929 用户基数小、链路纯净，对丢包敏感的业务表现突出；CMIN2 是移动用户的解法。真正完整的三网直连，是三条线路各走各的，而不是二选一。

**便宜的三网直连能买吗？** 可以，但要接受打折。$36.9/年那个价位的 T1 套餐标的是国际线路，不是优化线路；一些标"三网优化"的低价机，实际只有回程部分路由走了精品网。买之前要回程路由，比买之后骂客服有用。

**先买月付还是直接年付？** 如果你第一次用这家、或者业务还在验证阶段，先季付，跑一到两个晚高峰再决定要不要续长周期。线路质量这类东西，白天的测速数据参考价值有限。

**香港一定比洛杉矶快吗？** 延迟上通常是的，但香港 Pro 的月费是洛杉矶入门款的数倍。如果业务是建站、API、跨境电商后台这类对几十毫秒不敏感的场景，洛杉矶 Pro 的性价比更高。

选三网直连 VPS，本质上是在买"晚上八点之后还能正常用"这件事。CPU 和内存可以后面加，线路一旦买错，只能等下个计费周期。
